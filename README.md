## Sales & Customer Data Analysis using Python

### Project Overview
This project analyzes sales and customer transaction data using Python and Pandas to extract insights and support data-driven business decisions.

### Dataset Description
The dataset contains sales transactions with the following fields:
- OrderID: Unique order identifier
- Customer: Customer name
- Category: Product category
- Amount: Transaction value
- Month: Transaction month
- Employee: Sales employee

### Tools Used
- Python
- Pandas
- Jupyter Notebook

### Key Analysis
- Total and average sales calculation
- Sales aggregation by customer
- Identification of top-performing customers
- Monthly sales trend analysis using groupby operations

### Key Insights
- A small number of customers contribute the highest portion of total sales.
- Electronics category generates the highest transaction values.
- Sales performance varies across months, indicating potential seasonal trends.

### Outcome
This analysis demonstrates the use of Python and Pandas for data cleaning, aggregation, and basic business insight generation.
